# Approved GFA Driver Certificate Visual Baseline

**Approved by the GFA stakeholder on 8 September 2026.**

The approved visual reference is `GFA_Driver_Certificate_Sample_v2_NOT_VALID.png`. It is a fictional, non-production sample only and is not an issued certificate or an approved final production background asset.

The final GFA certificate renderer must retain the approved visual language: the existing GFA logo/contact header strip; white paper background; slim navy perimeter rule; straight green top rule; navy certificate title; green academy/programme qualifier; centred learner recognition; a restrained pale-blue three-column certificate metadata panel; and a small verification area with a QR code pointing only to the GFA verification reference.

The final design must not include blue or green curved/swooping decorative elements, a certification-authority signature block, commercial-document wording, quotation/invoice party or payment tables, a public document URL, a document access token, raw identity values, pricing, evidence-report content, RTMS content, SafeFreight behavioural data or incident-linked information.

The fictional sample watermark and sample-only status/footer must remain in design-review materials. The production renderer must replace these with the approved lifecycle status and required final issuance wording only after the certificate governance, signatory/legal wording, final native print asset, verification hostname and privacy controls have been approved.

A final print-ready master must be created and approved before production use. It should be GFA-owned, native to its selected A4 orientation, versioned and accompanied by safe text-zone specifications for longest expected learner/programme content. The sample image must be committed only to the GFA certificate-registry branch as a development/design-review reference; it must never be copied to BetterDriver.
